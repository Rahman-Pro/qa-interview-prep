## 🚀 Key Features of the Practice Console

*   **Interactive Keyword Grading Engine:** Write or speak your answer, and the console will analyze it against industry-standard keywords, giving you an automated score out of 10.
*   **Speech-to-Text Mock Interviews (Voice Practice):** Practice vocalizing your answers aloud using built-in browser speech recognition. Great for practicing communication skills.
*   **Topic Performance Map (Weakness Analysis):** Track your scores across different testing categories and instantly identify which QA topics need more preparation.
*   **Zero Dependencies & Offline-First:** No database, Node.js, or npm setup required. Just double-click the `index.html` file to run the app offline on your computer.
*   **Gamified Achievement Badges:** Unlock achievements (first step, perfect score, hot streak, champion) as you master questions.

## 🧠 QA Interview Domains Covered

### 🟢 Behavioral & Software Tester Basics
*   STAR template for behavioral questions.
*   Preventing bugs early in the release cycle.
*   Prioritizing regression test cases based on ROI.

### 🟡 Python & Advanced Scripting for QA
*   Core Python data structures, list comprehensions, and deep vs shallow copy.
*   API test automation using the `requests` library.
*   Excel and JSON file processing via `pandas` and `openpyxl`.
*   Running terminal OS commands using the `subprocess` module.

*   Selenium architecture, implicit vs explicit waits, and element stale errors.
